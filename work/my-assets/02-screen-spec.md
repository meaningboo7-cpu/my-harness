# 화면 설계: 내 자산 (my-assets)

## 목적
- 유저스토리 3에 따라 유료 멤버가 미션에 제출 완료한 제출물을 내 자산으로 전환하고, 직접 만든 프롬프트, 스킬 파일, 자동화 템플릿, 사용 사례를 자산으로 등록해 한곳에서 관리한다.
- 유저스토리 4에 따라 판매 승인 회원(seller)이 내 자산 중 일부를 골라 판매 신청하고, 검수 상태를 승인됨까지 확인한다.
- 멤버가 만든 자료는 기본적으로 비공개이며, 본인이 선택할 때만 멤버 공개 또는 판매 신청이 가능하다.

## 권한별 상태
- guest: 화면에 접근할 수 없다. 로그인 또는 회원가입 안내로 이동한다.
- free: 내 자산 등록 권한이 없다. 목록과 등록 버튼 없이 유료 전환 안내만 보인다.
- paid: 내 자산을 등록하고 목록을 볼 수 있다. 공개 범위는 비공개와 멤버 공개만 고를 수 있다.
- seller: paid 권한 전체에 더해 공개 범위에서 판매 신청을 선택할 수 있고, 판매 신청 상태를 확인한다.
- admin: 이 화면이 아니라 검수 화면에서 판매 신청을 검수한다(승인, 수정 요청, 반려).

## 구성요소
- [A-1] 상단 텍스트 탭 3개(비공개 / 멤버 공개 / 판매 신청)로 공개 범위별 목록을 나눠 본다. 선택된 탭은 밑줄과 굵은 글씨로 구분한다. seller가 아닌 회원에게는 판매 신청 탭도 보이지 않아 탭이 2개다.
- [A-2] 자산 카드는 자산 이름, 유형(카테고리), 공개 범위를 담고 우측에 상태 표시 자리를 둔다. 판매 신청 탭의 카드 상태 표시는 임시저장, 검수 대기, 수정 요청, 승인됨, 반려 중 하나이며 승인됨이 최종 상태다.
- [A-3] 자산이 없을 때 중앙 아이콘, 한두 줄 안내 문구, 새 자산 등록 버튼을 둔 빈 상태를 보여준다(자세한 내용은 빈·오류 상태).
- [A-4] 새 자산 등록의 공개 범위 선택은 설정 화면의 행 패턴(왼쪽 라벨, 오른쪽 현재 값과 화살표)으로 만든다. seller가 아닌 회원에게는 판매 신청 옵션을 잠근 상태로도 보여주지 않고 아예 노출하지 않는다.
- [A-4 변경 이유] 판매 신청은 seller만 할 수 있고 노출 조건도 seller이므로, 잠긴 옵션을 보여주면 서비스 규칙과 어긋나기 때문이다.
- [A-5] 하단 탭바에 내 자산 진입점을 두고 현재 위치 탭은 아이콘과 라벨로 강조한다. 탭은 MVP 1차 필수 기능 범위 안에서만 구성한다.
- 새 자산 등록 폼: 제목, 설명, 파일 첨부, 공개 범위를 입력한다. 제출 완료된 제출물에서 전환해 들어오면 제목, 설명, 파일이 채워진 상태로 시작한다.
- 공개 범위 기본값: 비공개
- 판매 신청 노출 조건: seller
- 확인 항목: 개인정보가 없음
- 확인 항목: 고객정보가 없음
- 확인 항목: 회사기밀이 없음
- 확인 항목: 저작권 문제가 없음
- 판매 신청을 고른 경우에만 위 확인 항목 4개를 모두 체크해야 신청 버튼이 활성화된다.

## 빈·오류 상태
- 빈 상태, 비공개 탭: 아직 등록한 자산이 없다는 안내와 새 자산 등록 버튼을 보여준다.
- 빈 상태, 멤버 공개 탭: 멤버 공개한 자산이 없다는 안내와 비공개 자산을 멤버 공개로 바꿀 수 있다는 한 줄 설명을 보여준다.
- 빈 상태, 판매 신청 탭(seller만): 판매 신청한 자산이 없다는 안내와 자산을 골라 신청하는 방법을 보여준다.
- 빈 상태, free 회원: 자산 등록은 유료 회원부터 가능하다는 안내와 유료 전환 안내를 보여준다.
- 오류 상태, 목록 불러오기 실패: 목록 영역에 실패 안내와 다시 시도 버튼을 보여주고 탭과 하단 탭바는 유지한다.
- 오류 상태, 등록 또는 판매 신청 실패: 입력한 내용을 유지한 채 실패 안내를 보여주고 다시 시도할 수 있게 한다.
- 오류 상태, 확인 항목 미체크: 판매 신청 시 4개 확인 항목이 모두 체크되지 않으면 신청 버튼을 비활성화하고 누락된 항목을 표시한다.
- 오류 상태, 수정 요청 또는 반려된 자산: 카드에 해당 상태를 표시하고, 수정 요청은 수정 후 다시 신청할 수 있다.
