# 레퍼런스 분석: my-assets

## 레퍼런스별 분석
- uibowl-class101.png: 클래스101 화면 3장. 가로 스크롤 카드 캐러셀과 "더 보기" 링크가 붙은 섹션 제목, 카드 우상단 북마크 아이콘, 6개 아이콘의 하단 탭바가 보인다. 한계: 온보딩, 홈, 문의 채팅 화면이라 자산 목록, 등록, 판매 신청 상태와는 직접 관련이 약하고 카드 목록과 하단 탭 패턴만 참고할 수 있다.
- uibowl-kmong.png: 크몽 화면 4장. 상단 3개 탭(서비스/포트폴리오/최근 본)이 있는 찜 목록에 아이콘과 안내 문구가 있는 빈 상태, 설정 화면의 행(언어 이동 화살표, 토글 스위치 2개), 소셜 로그인 버튼 나열, 카테고리 2단 목록이 보인다. 한계: 판매 신청 상태를 보여주는 화면은 없고, 등록 폼과 상태 배지도 보이지 않아 탭, 빈 상태, 설정 행 패턴만 근거로 삼는다.

## 서비스 반영 항목
- [A-1] 내 자산 화면 상단에 3개 이하의 텍스트 탭을 두고 공개 범위(비공개 / 멤버 공개 / 판매 신청)별로 목록을 나눠 본다. 선택된 탭은 밑줄과 굵은 글씨로 구분한다 | 레퍼런스: uibowl-kmong.png | PRD: §6-5
- [A-2] 내 자산 목록은 카드 한 장에 자산 이름, 유형, 공개 범위를 담고, 카드 우측에 상태 표시 자리를 둔다. 카드 목록 형태는 클래스101 홈의 카드 패턴을 따른다 | 레퍼런스: uibowl-class101.png | PRD: §6-5
- [A-3] 등록한 자산이 없을 때는 크몽 찜 목록처럼 중앙 아이콘, 한두 줄 안내 문구, 새 자산 등록 버튼을 둔 빈 상태를 보여준다 | 레퍼런스: uibowl-kmong.png | PRD: §6-5
- [A-4] 새 자산 등록의 공개 범위 선택을 설정 화면의 행 패턴(왼쪽 라벨, 오른쪽 현재 값과 화살표)으로 만든다. 판매 승인 회원이 아니면 '판매 신청' 선택지를 잠근 상태로 보여준다 | 레퍼런스: uibowl-kmong.png | PRD: §7-3, §7-4
- [A-5] 하단 탭바에 내 자산 진입점을 두고, 현재 위치 탭은 아이콘과 라벨로 강조한다. 탭 개수는 MVP 1차 필수 기능 범위 안에서만 구성한다 | 레퍼런스: uibowl-class101.png, uibowl-kmong.png | PRD: §9
