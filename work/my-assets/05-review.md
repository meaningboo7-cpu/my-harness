# 가이드 검수 결과: my-assets (S5 / G5)

`node judge/judge.js my-assets G5` 결과를 오케스트레이터가 기록한다. 검사 대상은 rules.json의 전체 규칙 21개다.

## 최종 결과

- 통과 (위반 0건)
- 검사한 규칙: G1-1~3, G2-1~2, G3-1, G3-4, D-01~D-05, G4-1~3, G5-1, S-B-1~3, S-A-1~2

## 이력

| 회차 | 결과 | 내용 |
|---|---|---|
| 1 | 실패 4건 (D-05) | screen-design.md 5, 8, 37, 60번 줄. `box-shadow: none. 설명 문장`처럼 none 뒤에 설명이 이어진 줄을 판정 스크립트가 값 전체로 읽어 위반으로 처리했다 |
| 원인 확인 | 오탐 | 산출물의 box-shadow는 4건 모두 none이었고 그림자를 쓴 곳은 없었다. 규칙(rules.json D-05: none은 허용)이 아니라 judge.js의 판정 오류였다 |
| 조치 | judge.js 수정 | `none`으로 시작하는 값은 허용하도록 고쳤다. 실제 그림자(`0 4px 8px`)와 `nonesuch` 같은 값은 여전히 걸린다. 회귀 테스트 2개를 추가했고 전체 53개가 통과했다 |
| 2 | 통과 (위반 0건) | G4 재판정 통과 후 G5 통과 |

산출물(01~04)은 이 조치로 바뀐 것이 없다.

- 하단 탭바 탭은 "홈"과 "내 자산" 2개만 뒀다. 03-keyscreens.md에 다른 탭 이름이 없어 지어내지 않았다. 탭 구성은 확정이 필요하다.

- `{colors.on-primary}`는 design.md에 값이 없어 screen-design.md에서 같은 흰색인 `{colors.canvas}`로 바꿨다.
