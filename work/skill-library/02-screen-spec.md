# 화면 설계: skill-library (스킬 라이브러리)

## 목적
- 스토리 2: 유료 멤버가 스킬 라이브러리에서 프롬프트와 스킬 파일을 찾아 복사·다운로드한다 (PRD §3-2, §6-3).
- 무료 회원은 샘플 프롬프트를 쓰고(§7-2), 접근 권한이 없는 카드는 개요를 미리 본 뒤 가입 또는 유료 전환으로 안내받는다.
- 화면은 두 개다. 1) 스킬 목록 2) 스킬 상세. 프레임은 390×844 기준이다.

## 권한별 상태
카드 권한(무료 / 유료 / 특정 코호트 전용)은 PRD §6-3, 역할별 접근은 §7을 따른다.
- guest: 목록과 모든 카드의 개요 필드를 볼 수 있다. 프롬프트·파일·예시 결과는 잠금이고 가입 안내를 보인다 (§7-1 가입 CTA).
- free: 카드 권한이 무료인 카드(샘플 프롬프트)는 복사·다운로드·예시 결과까지 쓴다. 유료·코호트 전용 카드는 개요만 보이고 잠금이며 유료 전환 안내를 보인다 (§7-2).
- paid: 카드 권한이 무료·유료인 카드를 모두 쓴다 (§7-3). 코호트 전용 카드는 해당 코호트 소속일 때만 열리고, 아니면 잠금이다. 카드 단위 접근 범위는 PRD가 "일부 또는 전체"로만 적어 운영 정책 확정이 필요하다.
- seller: paid와 동일하다. 이 화면에서 추가로 보이는 것은 없다 (§7-4).
- admin: 모든 카드를 열람할 수 있고 잠금이 없다 (§7-5 콘텐츠 관리 권한 기준). 스킬 카드 편집 UI는 이 화면에 두지 않는다.
- 설계 결정: 접근 권한이 없는 카드는 개요 필드(스킬명, 카테고리, 난이도, 추천 대상, 사용 도구, 언제 쓰나요?)만 보이고 프롬프트·파일·예시 결과는 잠금으로 보이게 한다. 이 잠금 안은 PRD §7-2의 "유료 자료 미리보기"를 근거로 한 설계 결정이며, PRD가 직접 정한 것이 아니다.

## 구성요소

### 1) 스킬 목록 화면
- 검색창: 상단 고정, 입력하면 자동완성 목록이 뜬다 (A-1, 기능 2 검색).
- 추천 검색어 칩: 검색창 아래 가로 스크롤 한 줄 (A-1).
- 태그 필터 칩과 난이도 칩: 가로 스크롤 한 줄, 복수 선택 가능 (A-2, 기능 3 태그 필터).
- 초기화 버튼: 필터가 하나라도 선택되면 칩 줄 맨 앞에 나타난다 (A-2).
- 결과 개수와 정렬 버튼: 한 줄에 배치한다. 정렬은 하단 시트에서 단일 선택(체크 표시)이다 (A-2).
- 스킬 카드 목록: 카드마다 스킬명 2줄과 보조 정보 한 줄(카테고리, 난이도, 사용 도구, 업데이트 날짜)을 보인다 (A-3, 기능 1 카드 목록, 기능 7 난이도 표시).
- 목록 배치 결정: 1열 리스트로 한다. 이유: 390px 폭에서 2열은 카드당 약 170px라 스킬명 2줄과 보조 정보 4개가 잘리기 때문이다.
- 카드 권한 표시: 카드 우측 상단에 무료 / 유료 / 코호트 전용 배지를 둔다. 접근 권한이 없는 카드에는 잠금 아이콘을 함께 둔다.
- 탭: 없다. 목록 화면은 카테고리 탭 대신 태그 필터 칩을 쓴다 (카테고리는 칩의 한 종류).

### 2) 스킬 상세 화면
- 상단 고정 탭: 개요 / 프롬프트·파일 / 사용 순서 / 예시·주의 (A-4, 탭 이름은 서비스 필드 기준으로 새로 정함).
- 개요 구획: 스킬명, 카테고리, 난이도, 추천 대상, 사용 도구, 언제 쓰나요?, 준비물, 업데이트 날짜, 카드 권한 배지.
- 프롬프트·파일 구획: 프롬프트 본문과 첨부 파일 목록.
- 사용 순서 구획: 번호가 붙은 단계 목록.
- 예시·주의 구획: 예시 결과 보기(기능 6)와 주의할 점. 예시 결과는 접이식 항목으로 펼친다.
- 관련 미션 연결: 상세 하단에 관련 미션 가로 목록 영역을 두고, 누르면 미션 상세로 이동한다 (A-5, 기능 8). 관련 스킬 가로 목록도 같은 영역에 둔다.
- 하단 고정 행동 바: 프롬프트 복사 버튼과 파일 다운로드 버튼 (A-6, 기능 4 복사 버튼, 기능 5 파일 다운로드).
  - 접근 권한이 있는 경우: 두 버튼 모두 활성이다. 첨부 파일이 없는 카드는 파일 다운로드 버튼을 숨긴다.
  - 접근 권한이 없는 경우: 두 버튼 대신 가입 또는 유료 전환 안내 버튼 하나만 보인다 (§6-1 CTA와 같은 취지).
- 잠금 표시: 프롬프트·파일·예시 결과 구획 위에 자물쇠 아이콘과 "이 스킬은 유료 멤버가 사용할 수 있어요" 안내 문구를 두고 본문은 가린다. 안내 문구 아래에 가입 또는 유료 전환 안내 버튼을 둔다 (권한별 문구는 guest: 가입, free: 유료 전환).

### 기능 8개 대응 (PRD §6-3)
- 카드 목록: 목록 화면 스킬 카드 목록
- 검색: 검색창과 자동완성
- 태그 필터: 태그·난이도 칩, 초기화
- 복사 버튼: 상세 하단 고정 행동 바
- 파일 다운로드: 상세 하단 고정 행동 바
- 예시 결과 보기: 상세 예시·주의 구획
- 난이도 표시: 목록 카드 보조 정보, 상세 개요, 난이도 칩
- 관련 미션 연결: 상세 하단 관련 미션 목록

## 빈·오류 상태
- 검색 결과 없음: 검색어를 보여 주고 "검색 결과가 없어요" 문구와 추천 검색어 칩을 다시 보인다.
- 필터 결과 없음: "조건에 맞는 스킬이 없어요" 문구와 초기화 버튼을 보인다.
- 목록 불러오기 실패: 오류 문구와 다시 시도 버튼을 보인다. 검색창과 필터 칩은 유지한다.
- 복사 실패 (클립보드 권한 등): 토스트로 "복사하지 못했어요"를 알리고, 프롬프트 본문을 길게 눌러 직접 선택할 수 있게 둔다.
- 파일 다운로드 실패: 토스트로 "다운로드하지 못했어요"를 알리고 다시 시도 버튼을 둔다. 다른 구획은 그대로 쓸 수 있다.
- 잠금 상태: 접근 권한이 없는 카드는 개요만 보이고 프롬프트·파일·예시 결과는 가려진다. 가입 또는 유료 전환 안내 버튼을 보인다.
- 관련 미션 없음: 관련 미션 영역을 숨긴다.
