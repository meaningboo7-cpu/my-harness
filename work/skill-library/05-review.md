## 사람이 확인할 것 (기계가 못 세는 것)

- 권한 잠금 방식(권한 없는 카드는 개요만 보이고 본문은 가림)은 PRD §7-2의 "미리보기"를 근거로 한 설계 결정이다. PRD가 직접 정한 것이 아니다.
- 코호트 전용 카드의 소속 판정: PRD §8의 User에 코호트 필드가 없어 판정 방식이 정해지지 않았다.
- 유료 회원의 접근 범위: PRD §7-3이 "일부 또는 전체"라고만 적어 운영 정책 확정이 필요하다.
- 관련 미션 연결: SkillCard와 Mission을 잇는 필드가 PRD §8에 없어 미션 제목을 표시용으로만 적었다.
- 레퍼런스(크몽, 클래스 101)는 상품 마켓 화면이라 권한 잠금, 복사·다운로드, 난이도, 관련 미션 연결은 레퍼런스에 없고 PRD 요구에서 가져왔다.
- 키스크린 2·3의 "관련 미션"과 맨 아래 여백은 하단 고정 바 때문에 프레임 안에 좌표를 두지 않고 "프레임 밖 스크롤 구획"으로만 적었다.
- `{colors.on-primary}`는 design.md에 값이 없어 같은 흰색인 `{colors.canvas}`로 바꿨다. 배지의 회색 반투명 스크림은 토큰 없이 적었다.
