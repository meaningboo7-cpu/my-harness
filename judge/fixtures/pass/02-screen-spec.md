# 화면 설계: 내 자산 (my-assets)

## 목적

멤버가 만든 자산을 목록으로 보고, 새 자산을 등록하고, 판매 신청 상태를 확인한다. (story-service 스토리 3, 4)

## 권한별 상태

- guest: 로그인 안내만 보인다
- free: 유료 전환 안내만 보인다
- paid: 자산 목록과 등록이 가능하고 공개 범위는 비공개 또는 멤버 공개만 고른다
- seller: paid 권한 전체에 더해 판매 신청을 고를 수 있다
- admin: 목록은 보이지만 검수는 검수 화면에서 한다

## 구성요소

- 자산 카드 목록: 제목, 공개 범위 칩, 검수 상태 칩
- 새 자산 등록 버튼
- 공개 범위 기본값: 비공개
- 판매 신청 노출 조건: seller
- 확인 항목: 개인정보가 없음
- 확인 항목: 고객정보가 없음
- 확인 항목: 회사기밀이 없음
- 확인 항목: 저작권 문제가 없음

## 빈·오류 상태

- 빈 상태: 아직 자산이 없어요, 새 자산을 등록해 보세요
- 오류 상태: 목록을 불러오지 못했어요, 다시 시도

## 데이터 필드

- Asset.title
- Asset.visibility
- Asset.review_status
- Asset.updated_at
